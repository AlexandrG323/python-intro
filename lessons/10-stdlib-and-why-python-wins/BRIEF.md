# Урок 10. stdlib и зачем Python в проде

Цель: собрать мини-скрипт на стандартной библиотеке и чётко сказать, где Python выигрывает, а где его не зовут.

## Карта

«Батарейки»: csv, json, pathlib, datetime, argparse, subprocess — без pip. Для курса Лицея этого хватит надолго.

`uv add пакет` / `uv run` — современная замена «глобальный pip install». Виртуальное окружение уже есть в этом репозитории.

Где Python берут в коммерции:

- скрипты и автоматизация (раз в день прочитать выгрузку);
- данные (CSV → агрегаты; дальше pandas/SQL — уже следующий курс);
- обвязка ИИ (вызвать API модели, склеить промпт, сохранить ответ);
- прототипы.

Где не берут как основной язык:

- прошивка и жёсткий realtime (ваш Arduino/ESP32);
- горячий путь игры / ядра;
- команда, у которой уже Nest+TS и нет причины плодить второй стек.

Компромисс: скорость разработки vs скорость CPU vs экосистема команды.

## Упражнения

Файл `exercises/report.py`. Данные: `data/prices.csv` (те же колонки, что в уроке 7).

Для каждого продукта **первый год** = минимальный год в файле у этого продукта, **последний** = максимальный. Прирост: `(price_last - price_first) / price_first` (обычное деление float).

- `yearly_totals(path: Path) -> dict[int, float]` — сумма всех цен за год.
- `max_increase(path: Path) -> tuple[str, float]` — продукт с **наибольшим** приростом и сам прирост. При равенстве — имя, которое меньше лексикографически.
- `format_report(totals: dict[int, float]) -> str` — годы по возрастанию, каждая строка `{year}: {total:.2f}`, строки через `\n`, без перевода строки в конце.
- `when_not_python(job: str) -> bool` — `True`, если в нижнем регистре есть любое из: `firmware`, `realtime`, `embedded`, `gpu kernel`. Иначе `False`.
