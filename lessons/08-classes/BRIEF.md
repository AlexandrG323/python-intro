# Урок 8. Классы

Цель: увидеть, чем `class` в Python отличается от класса C++, и когда достаточно `@dataclass`.

## Карта

В Python класс — тоже объект. Экземпляр хранит атрибуты в словаре `__dict__` (упрощённо). Первым аргументом метода всегда приходит сам экземпляр: его принято звать `self` (это соглашение, не ключевое слово).

Нет настоящего `private` как в C++. Префикс `_name` — «не трогай снаружи, пожалуйста». `__name` включает name mangling — это не безопасность, а защита от случайного пересечения имён в наследниках.

Сборщик мусора (reference counting + цикл-детектор в CPython) вместо деструктора, который обязан освободить память. `__del__` не аналог C++ destructor для ресурсов: для файлов и сокетов используйте `with`.

Утиная типизация: если объект имеет `.price`, функция может его просуммировать — без общего базового класса и без `implements` как в TypeScript.

Современный стандарт для «структура с данными»: `@dataclass`. `frozen=True` — неизменяемый экземпляр (похоже на желание `const` / объекта-значения). Методы, которые «меняют» frozen, возвращают **новый** объект.

`__len__` позволяет писать `len(basket)` — протокол, не интерфейс в смысле Java.

## Аналогии

- C++: конструктор, `this`, private/public, деструктор, виртуальные методы, правило трёх/пяти.
- TypeScript: `class` и интерфейсы; утиная типизация ближе к структурной типизации TS.
- NestJS DTO — данные + мало поведения. Dataclass часто играет эту роль.

## Упражнения

Файл `exercises/basket.py`.

`Product` уже объявлен как frozen dataclass с полями `name: str` и `price: float`. Допишите:

- `Product.with_discount(self, percent: float) -> Product` — новая цена `price * (1 - percent / 100)`. Имя то же. Не мутируйте self (frozen и так запретит).
- Класс `Basket`:
  - `__init__` — пустой список `_items`;
  - `add(product: Product) -> None` — положить в конец;
  - `total() -> float` — сумма `.price`;
  - `__len__` — число позиций.
- `total_of(items) -> float` — сумма `.price` у любого iterable объектов с атрибутом `price` (утиная типизация). Пустой iterable → `0.0`.
