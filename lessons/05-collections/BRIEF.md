# Урок 5. Коллекции

Цель: выбрать list / tuple / dict / set осмысленно и собрать данные так, как вы уже делали в whiskyindex (сумма по ключу).

## Карта

| Тип | Смысл | Похоже на |
| --- | --- | --- |
| `list` | последовательность, можно менять | `std::vector`, TS array |
| `tuple` | фиксированная запись | что-то вроде пары/структуры без имён |
| `dict` | ключ → значение | `std::unordered_map`, TS object / `Map` |
| `set` | уникальные элементы | `std::unordered_set` |

Индексация с `0`. Отрицательный индекс: `-1` — последний. Срез `xs[1:3]` — полуинтервал.

**Comprehension**: `[x * x for x in xs if x > 0]` — тот же цикл, короче. Не складывайте в одну строку три уровня.

Ключ словаря должен быть хешируемым: `str`, `int`, `tuple` из неизменяемого. `list` ключом быть не может.

## Аналогии

- Корзина whiskyindex: продукт + год + цена → «сумма по году» — это dict.
- Serial-меню Arduino: набор команд без повторов — set.
- C++: `push_back` vs `append`; итерация по `map` даёт пары, в Python `for key, value in d.items()`.

## Наводящие вопросы

1. Когда tuple лучше list? Когда set лучше list для «уже видели это имя»?
2. Что сломается, если ключом dict сделать список?
3. Чем comprehension отличается от `map`/`filter` в JS — и когда цикл читаемее?

## Упражнения

Файл `exercises/collections_practice.py`.

Строки для подсчёта слов: режьте `str.split()` без аргументов (пробелы/табы/переводы строк). Регистр не меняйте.

- `unique_sorted(xs: list[str]) -> list[str]` — уникальные, отсортированные по возрастанию.
- `word_counts(text: str) -> dict[str, int]` — сколько раз слово встретилось.
- `top_n(counts: dict[str, int], n: int) -> list[tuple[str, int]]` — топ `n` пар `(слово, счёт)`. Сначала по счёту **убывание**, при равенстве — слово **по алфавиту**. Если `n` больше числа ключей — вернуть все.
- `flatten(matrix: list[list[int]]) -> list[int]` — один список; пустые строки внутри пропускаются. Удобно comprehension.
- `even_squares(xs: list[int]) -> list[int]` — квадраты **чётных** элементов, в исходном порядке.
- `total_by_year(rows: list[tuple[str, int, float]]) -> dict[int, float]` — ряд `(product, year, price)` → сумма цен по году.
