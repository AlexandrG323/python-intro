# Заметки: функции

Пиши своими словами после разбора. Не копируй BRIEF.

## Простыми словами
Функция это объект и переиспользуемый кусок кода который принимает аргументы и возвращает результат
## Чем это отличается от C++ / TypeScript
Нет строгой статической типизации на уровне выполнения и дефолтные аргументы создаются один раз при объявлении а не при каждом вызове 
## Что происходит под капотом
Дефолтные аргументы создаются один раз при def и хранятся в объекте функции порядок поиска имен (LEGB): сначала внутри функции (Local) потом в объемлющей (Enclosing/замыкание) затем в модуле (Global) и среди встроенных (Built-in вроде len) присваивание внутри функции делает имя локальным на всю функцию
## Что умею объяснить вслух
Почему нельзя использовать мутабельный дефолт (⁠[]⁠) как работают замыкания
