# Урок 1. Почему Python

Цель: своими словами объяснить, чем Python отличается от C++ и TypeScript и в каких задачах его берут первым.

Это вводное занятие. Кода мало — важнее карта в голове.

## Зачем этот язык

Python — язык с интерпретатором (обычно CPython): вы запускаете `.py`, не собираете бинарник как скетч Arduino и не прогоняете `tsc`. Типы проверяются в основном на лету. Из-за этого цикл «написал → увидел результат» короткий: скрипты, разбор CSV, эксперименты с данными, обвязка вокруг моделей ИИ.

Компромисс: проще писать и читать, медленнее горячий путь и нет голого железа. Прошивку ESP32 на Python не кладут. NestJS API whiskyindex на Python тоже не обязаны переписывать — там уже TypeScript и строгие контракты.

## Аналогии

- C++ / Arduino: компилятор, фиксированный `int`, один `loop()`, вы сами следите за памятью и типами.
- TypeScript: типы до запуска (`tsc` / Vite), async и модули как в Nest. В Python type hints **не компилируют** программу — это документация и помощь редактору.
- whiskyindex: агрегации цен — типичная зона Python (скрипт + CSV). Сайт и API — зона TypeScript.

## Упражнение

Файл: `exercises/pick_language.py`.

Функция `pick_language(job: str) -> str` возвращает `"cpp"`, `"typescript"` или `"python"`.

Правила (проверяйте в таком порядке, строку заранее приведите к нижнему регистру):

1. Есть любое из: `arduino`, `esp32`, `firmware`, `microcontroller`, `gpio` → `"cpp"`.
2. Иначе есть любое из: `nestjs`, `react`, `frontend` → `"typescript"`.
3. Иначе есть любое из: `csv`, `script`, `pandas`, `llm`, `dataset`, `notebook` → `"python"`.
4. Иначе — `ValueError` с текстом `unknown job`.

Если сработали несколько групп — побеждает более ранний пункт (железо важнее веба важнее скрипта).

Запуск тестов:

```bash
uv run pytest lessons/01-why-python
```
