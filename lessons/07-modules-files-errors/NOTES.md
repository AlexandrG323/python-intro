# Заметки: модули, файлы, ошибки

Пиши своими словами после разбора. Не копируй BRIEF.

## Простыми словами
мы работаем с файлами через path и with читаем csv с помощью dictreader переводим типы и ловим конкретные ошибки
## Чем это отличается от C++ / TypeScript
with автоматически закрывает без try и сразу отдает строчки 
## Что происходит под капотом
конструкция with гарантировано закрывает файл при выходе из блока. keyerror возникает когда запись ненайдена а valueerror когда строка не превращается в число
## Что умею объяснить вслух
with нужен для работы с файлами почему типы из csv надо приводить вручную и чем keyerror отличается от valueerror
