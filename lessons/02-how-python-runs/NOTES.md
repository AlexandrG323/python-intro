# Заметки: как выполняется код

Пиши своими словами после разбора. Не копируй BRIEF.

## Простыми словами
сначала файл с пайтоном переводится в байткод и уже его исполняет cpython
## Чем это отличается от C++ / TypeScript
в с++ есть только один main а в пайтоне файл может быть и библиотекой и скриптом
## Что происходит под капотом
импорт происходит один раз а при повторе берется результат функции из кэша
## Что умею объяснить вслух
в пайтоне по сравнению с с++ все заточено под скорость работы с кодом и удобство разработчика теперь могу объяснить в слух как работает импорт и что файл может быть или скриптом или библиотекой в пайтоне
